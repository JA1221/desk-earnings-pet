錢進中 使用說明
========================

【這是什麼】

錢進中是一個 Windows 桌面小程式。上班時間，畫面上會一秒一秒顯示「今天已經賺到多少錢」，旁邊有一隻小寵物（黃金鼠或貓咪）陪你打字、午休、下班。

1.1 版起，寵物也會提醒你起來動一動、順便喝水，想專心時還有番茄鐘（見「休息提醒怎麼開關」「番茄鐘怎麼用」）。

・只有一個 錢進中.exe，不用安裝，也不需要系統管理員權限。
・薪資資料只存在這台電腦裡，不會上傳到任何地方（例外見「資料存放在哪裡」）。
・版本、使用說明和第三方授權：「設定」→「其他」，最下面的「使用說明」「第三方授權」點一下就會打開。

【系統需求】

・Windows 10（1903 以後的版本）或 Windows 11。
・Microsoft Edge WebView2 執行階段：Windows 11 已內建，大部分 Windows 10 電腦也已經裝好了。
  ・如果缺少，錢進中開啟時會告訴你，請到 https://go.microsoft.com/fwlink/p/?LinkId=2124703 下載安裝，再重新開啟錢進中。
  ・微軟官方說明頁：https://developer.microsoft.com/microsoft-edge/webview2/。一般使用者不需要系統管理員權限就能安裝。
・其他都不用裝（.NET Framework 4.8 是 Windows 內建的）。

【第一次執行】

1. 把 錢進中.exe 放在一個固定的地方，例如「文件」裡新增一個資料夾。
   ・開機自動啟動會記住 exe 的位置，所以不要放在之後會清掉的地方（例如「下載」）。
   ・之後要搬家也沒關係：從新位置開一次，開機啟動就會跟著更新。
2. 點兩下開啟。exe 沒有數位簽章，第一次開可能會出現藍色的「Windows 已保護您的電腦」（SmartScreen）。
   ・點「其他資訊」，再點「仍要執行」。只有第一次需要這樣做。
   ・如果公司電腦不允許執行沒有簽章的程式，或被防毒軟體擋下，請找公司 IT 協助。
3. 第一次開啟會花幾秒準備程式需要的檔案（放在 %LocalAppData%\錢進中\app），之後開啟就會很快。
4. 跟著歡迎畫面設定（共 3 步）：
   ・輸入薪水：月薪或時薪都可以。
   ・選一隻寵物，幫牠取名字。
   ・要不要提醒你起來動、喝水？兩個都預設打勾，不想要就取消勾選，再按「開始！」。
   ・其他設定（每天工時、午休時間……）之後都能在「設定」裡改。

【每天怎麼用】

・開機登入 Windows 後，錢進中會自己開啟。
・上班日（預設週一到週五）會自動開始算錢：起算時間是今天第一次登入或解鎖 Windows 的時間。
  ・時間不對的話，用右鍵選單的「調整起算時間」修改，金額會立刻重算。
  ・週末或「今天休假」不會自動開始，需要的話可以按「開始上班」。
・今天放假：「設定」→「薪水和時間」，打開最上面的「今天休假」。
  ・今天就不算錢：金額歸零，狀態顯示「休假日」，這一天在紀錄裡是 0 元。
  ・開機後已經自動開始算錢也沒關係，打開就會歸零。
  ・打錯了就再關掉，金額會照原本的起算時間恢復。
  ・休假日臨時要上班：按「開始上班」，就從那一刻開始算（「今天休假」會自動關掉）。
・金額只看時鐘：鎖定螢幕、電腦睡眠、離開座位開會，都照樣算錢。
・午休預設是中午 12:00–13:00，這段時間不算錢；要改的話：「設定」→「薪水和時間」。
・工作滿 8 小時（預設，扣掉午休）就會顯示「可以下班」，金額停住。例如 8:30 起算，17:30 可以下班。
・要提早走：按「下班」，今天的金額就停在那一刻，狀態變成「已下班」。
・不小心按到「下班」：右鍵選單裡同一格會變成「繼續上班」，當天按它就會接著算，中間的時間也照算（「設定」→「薪水和時間」也有「繼續上班」）。
・忘了按「下班」就鎖定螢幕、關機或登出：如果那時還沒到下班時間，隔天打開時寵物會問你「昨天是不是 16:02 就下班了？」，選一個答案，紀錄就會照著寫。

【休息提醒怎麼開關】

上班一坐就是一整天，錢進中會幫你記著：每坐 50 分鐘（預設），寵物會捧著水杯跳出來揮手，冒出一個大泡泡「起來動一動，順便喝口水～」。

・只有一個提醒：起來動和喝水共用同一個計時，不會各叫各的。
・兩個開關：「設定」→「健康」→「休息提醒」裡的「起來動」和「喝水」。
  ・兩個都開：一次問兩件事，按鈕是「喝了」「起來了」「等一下」。
  ・只開起來動：只叫你起來動，按鈕是「起來了」「等一下」。
  ・只開喝水：只叫你喝水，按鈕是「喝了」「等一下」；今天喝滿目標後，當天就不再提醒。
  ・兩個都關：不會提醒。記杯數和番茄鐘還是可以照常用。
・泡泡上的按鈕：
  ・「喝了」：記一杯水，也算一次起來動（起身去倒水也是起來動），計時重新開始。
  ・「起來了」：算一次起來動，計時重新開始。
  ・「等一下」：泡泡先收起來，10 分鐘後再提醒一次。
  ・都不按：泡泡會一直留著，寵物每 2 分鐘再揮一次手，但不會多冒泡泡。
・只在上班中提醒：還沒上班、午休、可以下班或已下班、今天休假的時候都不提醒，計時也不跑。
  ・鎖定螢幕的時間不算。一次鎖 5 分鐘以上，就當作你已經起來活動過了：算一次起來動，計時重新開始。
・不會搶走打字焦點：提醒出現時，錢進中會移到所有視窗的最上面讓你看到，但你正在打的字不受影響；泡泡收起來後，恢復原本的置頂設定。不會發出聲音，也不會跳出 Windows 通知。
・全螢幕和簡報時提醒會先等著：錢進中被藏起來（快速隱藏快捷鍵或選單的「隱藏」）、正在專心（番茄鐘），或 Windows 正在全螢幕或簡報模式（例如投影片放映、全螢幕的影片或遊戲）時，到時間的提醒先排隊，等這些情況結束 3 秒後才出來。番茄鐘的泡泡也一樣，但番茄鐘的倒數照樣在跑。
・一天 8 杯：喝水的目標預設一天 8 杯。喝滿目標，寵物會冒愛心誇你。
・記一杯水：按提醒的「喝了」、右鍵選單最上面的「記一杯水」，或版型上的水杯按鈕，都會記一杯。記錯了，到「設定」→「健康」→「進階」的「今天已喝」用 − ＋ 改。
・沒在用的數字不會出現：杯數只在喝水提醒開著、或今天記過水時才顯示；番茄數只在今天完成過番茄、或正在專心時才顯示。都沒在用的話，畫面就跟 1.0 一樣。開始番茄鐘的按鈕一直都在，U12 的三個圓圈也一直都在。
・「設定」→「健康」：
  ・休息提醒：「起來動」「喝水」兩個開關、每隔幾分鐘提醒（20–120 分鐘，預設 50）、一天幾杯（1–20 杯，預設 8）。
  ・番茄鐘：專心幾分鐘（10–90 分鐘，預設 25）。
  ・「進階」點開才看得到：短休息（預設 5 分鐘）、長休息（預設 15 分鐘）、每幾顆番茄長休息一次（預設 4 顆），和今天已喝幾杯（− ＋）。
  ・起來動的目標是自動算的：每天工時 ÷ 提醒間隔（8 小時、每 50 分鐘 → 每天 9 次）。
・從 1.0 升級的人：第一次開啟 1.1 時，會單獨問一次「要不要提醒你起來動、喝水？」，兩個選項預設打勾，按「確定」才算回答。
  ・回答之前，兩個提醒都不會開；直接關掉不回答，下次開啟會再問。
  ・原本的設定、紀錄和視窗位置都保留，不會改動。
・紀錄：右鍵選單 →「紀錄」，收入圖下面多了一張「健康月曆」：格子越藍代表那天喝越多，打勾代表喝滿目標，右下角是那天完成的番茄數。

【番茄鐘怎麼用】

想專心做一件事的時候，可以開番茄鐘：專心 25 分鐘、休息 5 分鐘，每完成 4 顆番茄，那次休息改成長休息 15 分鐘。時間都能在「設定」→「健康」裡改。

・開始：
  ・右鍵選單（或系統匣的金幣圖示）最上面的「開始番茄鐘」。進行中會變成「停止番茄鐘（還剩 N 分）」。
  ・或按版型上的番茄鐘按鈕：U1 金額下面那排小膠囊的「▶ 番茄鐘」、U3 的番茄按鈕、U5-B 右邊那欄的番茄按鈕、U10 展開後的番茄按鈕、U13 的大圓圈「開始專心」。U7、M3 和 U12 請從右鍵選單開始。
  ・進行中再按同一個按鈕就是停止。專心到一半停止，這顆不算完成。
・專心中：寵物戴上耳機拚命打字，不聊天。寵物外面有一圈倒數（專心是紅色，休息是綠色），寫著還剩幾分鐘。休息提醒會等到休息時再說。
・專心結束：番茄數 +1，休息馬上開始計時。寵物伸懶腰，泡泡寫「休息 5 分鐘！起來走走～」，按「好」；按「跳過休息」就直接開始下一顆。開始休息也算一次起來動。
・休息結束：泡泡問「休息結束～要開始下一顆嗎？」，按「開始」或「先不要」。不按的話，不會自己開始下一顆。
・任何時候都能開始，包括午休和下班後；完成的番茄算在開始的那一天。每天的目標是一輪（預設 4 顆）。
・鎖定螢幕、把錢進中藏起來，甚至關掉再打開，番茄鐘都照樣倒數；關掉期間時間到了，這顆也照算完成。

【視窗與選單】

・選單：在視窗上按右鍵，或在工作列右下角的金幣圖示上按右鍵，就會出現選單：
  ・記一杯水（有在記杯數時，旁邊寫今天喝了幾杯，例如 3/8）、開始番茄鐘（進行中是「停止番茄鐘（還剩 N 分）」）、餵食（旁邊是現在有幾個零食）。
  ・開始上班／下班／繼續上班：同一格，跟著狀態變。還沒上班時是「開始上班」，上班中是「下班」，按過下班是「繼續上班」。旁邊是「調整起算時間」。
  ・版型 ▶：切換版型、縮成迷你、永遠在最上層；用 U10 時還有「膠囊位置」。
  ・紀錄、設定、隱藏、結束。
・找不到金幣圖示？ Windows 11 和 Windows 10 都可能把新的圖示收在工作列右下角的「^」（隱藏的圖示）裡。
  ・把金幣從「^」裡拖到工作列上，以後就一直看得到。
  ・或者用設定打開：Windows 11 是「設定」→「個人化」→「工作列」→「其他系統匣圖示」，把「錢進中」打開；Windows 10 是「設定」→「個人化」→「工作列」→「選取要在工作列上顯示的圖示」。
・移動視窗：按住視窗拖曳就能移動。每個版型的位置都會記住。
・版型：
  ・U1 經典直式
  ・U3 遊戲畫面
  ・U5-B 橫向極簡
  ・U7 桌面寵物：只有寵物和金額，背景透明
  ・U10 頂端小膠囊、U12 健康儀表板、U13 番茄鐘優先：1.1 新增的三個版型，見「三個新版型」
  ・M3 迷你徽章：「縮成迷你」，在迷你徽章上點兩下（或再點一次選單的「縮成迷你」）就回到原本的版型
・下次開啟會用你最後用的版型（第一次是 U1）。縮成迷你時關掉，下次開啟也是迷你徽章。
・不會搶走打字焦點：點桌面寵物（U7）、迷你徽章（M3）或頂端小膠囊（U10）時，你正在打字的程式會保有鍵盤焦點，可以放心戳寵物。
・永遠在最上層：右鍵選單 →「版型」→「永遠在最上層」，切換目前的版型。每個版型分開記住，預設只有 U7、M3 和 U10 會置頂。
・視窗周圍出現黑框或黑色背景？ 請到「設定」→「畫面」打開「相容模式（不透明背景）」。
  ・有些電腦（例如遠端桌面、關閉了 Windows「透明效果」、比較舊的 Windows 10）沒辦法顯示透明背景，透明的地方會變成黑色。
  ・打開後，視窗的背景會變成米白色，不再透明；點擊的範圍不變。
  ・如果錢進中一開啟就發現這台電腦不能顯示透明背景，會自動使用相容模式。
・省電模式：「設定」→「畫面」→「省電模式」，預設關閉，筆電建議打開。
  ・金額每秒跳 4 次（平常是 10 次），一直在跑的裝飾動畫會停下來。
  ・寵物大部分時間安靜地坐在鍵盤前，偶爾才動一下；被點、餵食和提醒時照常有反應。
  ・蠟筆造型的紋理改成不會動的。
・Alt+F4 只會隱藏視窗，程式還在背景算錢。要真正關閉，請用選單裡的「結束」。

【三個新版型（U10 頂端小膠囊、U12 健康儀表板、U13 番茄鐘優先）】

從右鍵選單 →「版型」切換。和其他版型一樣，都看得到今天賺多少、上班狀態、下班倒數和寵物；有在用的話，也會顯示杯數、番茄數和下次起來動的時間。

・U10 頂端小膠囊：一顆深色的小膠囊，預設在螢幕上方正中間，佔的位置最小。
  ・滑鼠移上去會展開，看得到完整的金額，還有記一杯水和番茄鐘的按鈕。
  ・提醒時像來電一樣變寬，按鈕就在膠囊上；專心時，膠囊上顯示倒數。
  ・一直在最上層、不會搶走打字焦點，膠囊以外的地方滑鼠點得穿。
  ・膠囊位置：右鍵選單 →「版型」→「膠囊位置」，可以選上方正中間、左下、中下、右下（「下」是工作列正上方）。這一項只有用 U10 時才會出現。
  ・也可以直接拖著走：放開時會吸到那個螢幕上最近的位置，所以也能拖到別的螢幕。
・U12 健康儀表板：一張卡片。上面是金額和下班倒數，中間三個圓圈（喝水、番茄、起來動），下面是寵物告訴你下次什麼時候起來動。
  ・點喝水的圓圈就記一杯水。番茄鐘進行中，番茄的圓圈改成倒數。提醒時，起來動的圓圈會發光。
・U13 番茄鐘優先：中間一個大倒數圈，寵物坐在圈邊。沒在專心時，整個圓圈就是一顆大大的「開始專心」按鈕。
・U12 和 U13 跟 U1 一樣是一般視窗：預設不置頂，可以拖曳，位置會記住。

【隱藏視窗與防截圖】

・快速隱藏快捷鍵：預設是 Ctrl+Alt+H，按一下隱藏，再按一下恢復。如果視窗被其他視窗蓋住，第一下會先把它移到最前面，再按一下才隱藏。
  ・要換的話：「設定」→「其他」，點快捷鍵的框，再按下新的組合鍵（要有 Ctrl 或 Alt）。
  ・如果這組按鍵已經被其他程式使用，錢進中會提示你，請換一組。
・視窗藏起來了，怎麼叫回來？ 任選一種：
  ・按快速隱藏快捷鍵。
  ・在工作列的金幣圖示上點兩下。
  ・在金幣圖示上按右鍵，選「顯示」。
  ・再點兩下 錢進中.exe，原本開著的錢進中就會出現。
・防截圖（預設開啟）：自己的螢幕照樣看得到錢進中，但是分享螢幕（例如 Teams 會議）、錄影、截圖都拍不到它。
  ・比較舊的 Windows 10（2004 以前的版本）沒辦法完全隱形，會拍到一塊黑框。
  ・要關掉的話：「設定」→「其他」→「分享螢幕、錄影、截圖時隱形」。
・接投影機或會議室螢幕之前，先按 Ctrl+Alt+H 隱藏錢進中。 防截圖擋不住第二個螢幕：投影機、會議室的電視和延伸螢幕都是真的螢幕，錢進中在上面照樣看得到。

【開機自動啟動】

・預設開啟。錢進中只會寫入「目前使用者」的開機項目，不需要系統管理員權限。
・要關掉：「設定」→「其他」→ 關閉「登入 Windows 後自動開啟」。

【資料存放在哪裡】

按 Win + R，貼上下面的路徑，按 Enter，就能打開資料夾。

・%AppData%\錢進中：你的資料。
  ・settings.json：設定（包含薪資）。
  ・history.json：每天的紀錄（也包含每天喝了幾杯、完成幾顆番茄、起來動幾次，和進行中的番茄鐘）。
  ・window.json：視窗位置。
  ・settings.json.bak、history.json.bak、window.json.bak：每次存檔前的上一個版本。主檔案壞掉或變成空白時（例如存檔時突然斷電），錢進中會自動改用它。
  ・session.json：錢進中上次結束的時間（關機、登出時記下），用來判斷前一天是不是提早下班。
  ・檔名後面加了 .corrupt- 和日期時間的檔案：讀不出來的檔案留下的副本，確定不需要的話可以刪掉。
  ・換電腦時，把這個資料夾複製過去就能接著用。
・%LocalAppData%\錢進中：程式自己用的檔案，刪掉也沒關係，下次開啟會重新產生。
  ・app\：程式執行時需要的檔案。
  ・WebView2\：顯示畫面用的瀏覽元件資料。
  ・error.log：發生錯誤時的紀錄。

這些資料只存在這台電腦裡，錢進中不會把它們上傳到任何地方。

・例外：如果公司把 Windows 設定成「漫遊設定檔」，或把 AppData 資料夾重新導向到公司的伺服器，%AppData%\錢進中（包含薪資）會跟著其他個人設定一起存到公司的伺服器上。不確定的話，請問公司 IT。

【移除】

錢進中沒有安裝任何東西到系統裡，照下面做就移除乾淨了：

1. 在設定裡關閉開機啟動：「設定」→「其他」→ 關閉「登入 Windows 後自動開啟」。
2. 關閉程式：右鍵選單 →「結束」。
3. 刪除 錢進中.exe。
4. 刪除 %AppData%\錢進中 與 %LocalAppData%\錢進中 這兩個資料夾（按 Win + R，貼上路徑打開，再刪除）。

如果先刪了 exe、忘了第 1 步：開機項目會留下一筆指向已刪除檔案的紀錄。它不會執行任何東西，也不會造成問題。

・不想看到它：到「工作管理員」→「啟動應用程式」，把「錢進中」停用。停用只是不讓它執行，紀錄還在。
・想把紀錄刪掉：把 錢進中.exe 放回來開一次，照上面第 1 步關閉開機啟動，再照第 2、3 步結束、刪除。

【常見問題】

・出現「這台電腦缺少 Microsoft Edge WebView2 執行階段」：請照「系統需求」安裝 WebView2，再重新開啟。
・出現「錢進中無法準備執行所需的檔案」：程式放在 %LocalAppData%\錢進中\app 的檔案寫不進去或壞掉了（例如磁碟滿了，或被防毒軟體擋住）。
  ・先關掉這個訊息，按 Win + R 貼上 %LocalAppData%\錢進中\app，把整個 app 資料夾刪掉，再重新開啟錢進中。
  ・你的設定和紀錄在 %AppData%\錢進中，不受影響。
  ・如果還是不行，請把 %LocalAppData%\錢進中\error.log 交給提供程式給你的人。
・出現「錢進中發生錯誤」或「無法顯示畫面」：詳細資訊記錄在 %LocalAppData%\錢進中\error.log。重新開啟通常就會好；如果一直發生，請把這個檔案交給提供程式給你的人。
・金額不對：先確認「設定」→「薪水和時間」裡的薪資和計算方式，再看起算時間對不對（右鍵選單 →「調整起算時間」）。今天如果是休假，請打開「設定」→「薪水和時間」→「今天休假」。
・視窗周圍是黑的：打開「設定」→「畫面」→「相容模式（不透明背景）」（見「視窗與選單」）。
・會不會拖慢電腦？ 錢進中很輕量。視窗隱藏或螢幕鎖定時，動畫會暫停。用筆電或想更省電的話，打開「設定」→「畫面」→「省電模式」（見「視窗與選單」）。
・提醒沒有出現：先看「設定」→「健康」的「起來動」「喝水」有沒有打開。提醒只在上班中出現；錢進中藏起來、正在專心，或在全螢幕和簡報時，提醒會先等著（見「休息提醒怎麼開關」）。
