# 錢進中 使用說明

## 這是什麼

錢進中是一個 Windows 桌面小程式。上班時間，畫面上會一秒一秒顯示「今天已經賺到多少錢」，旁邊有一隻小寵物（黃金鼠或貓咪）陪你打字、午休、下班。

- 只有一個 `錢進中.exe`，不用安裝，也不需要系統管理員權限。
- 薪資資料只存在這台電腦裡，不會上傳到任何地方。

## 系統需求

- Windows 10（1903 以後的版本）或 Windows 11。
- Microsoft Edge WebView2 執行階段：Windows 11 已內建，大部分 Windows 10 電腦也已經裝好了。
  - 如果缺少，錢進中開啟時會告訴你，請到 <https://go.microsoft.com/fwlink/p/?LinkId=2124703> 下載安裝，再重新開啟錢進中。
  - 微軟官方說明頁：<https://developer.microsoft.com/microsoft-edge/webview2/>。一般使用者不需要系統管理員權限就能安裝。
- 其他都不用裝（.NET Framework 4.8 是 Windows 內建的）。

## 第一次執行

1. 把 `錢進中.exe` 放在一個固定的地方，例如「文件」裡新增一個資料夾。
   - 開機自動啟動會記住 exe 的位置，所以不要放在之後會清掉的地方（例如「下載」）。
   - 之後要搬家也沒關係：從新位置開一次，開機啟動就會跟著更新。
2. 點兩下開啟。exe 沒有數位簽章，第一次開可能會出現藍色的「Windows 已保護您的電腦」（SmartScreen）。
   - 點「其他資訊」，再點「仍要執行」。只有第一次需要這樣做。
   - 如果公司電腦不允許執行沒有簽章的程式，或被防毒軟體擋下，請找公司 IT 協助。
3. 第一次開啟會花幾秒準備程式需要的檔案（放在 `%LocalAppData%\錢進中\app`），之後開啟就會很快。
4. 跟著歡迎畫面設定：
   - 輸入薪水：月薪或時薪都可以。
   - 選一隻寵物，幫牠取名字，按「開始！」。
   - 其他設定（每天工時、午休時間……）之後都能在「設定」裡改。

## 每天怎麼用

- 開機登入 Windows 後，錢進中會自己開啟。
- 上班日（預設週一到週五）會自動開始算錢：起算時間是今天第一次登入或解鎖 Windows 的時間。
  - 時間不對的話，用右鍵選單的「調整起算時間」修改，金額會立刻重算。
  - 週末或「今天休假」不會自動開始，需要的話可以按「開始上班」。
- 金額只看時鐘：鎖定螢幕、電腦睡眠、離開座位開會，都照樣算錢。中午 12:00–13:00 午休不算錢。
- 工作滿 8 小時（扣掉午休）就會顯示「可以下班」，金額停住。例如 8:30 起算，17:30 可以下班。
- 要提早走：按「下班」，今天的金額就停在那一刻，狀態變成「已下班」。

## 視窗與選單

- **選單**：在視窗上按右鍵，或在工作列右下角的金幣圖示上按右鍵，就會出現選單：
  - 切換版型、縮成迷你、餵食、開始上班、調整起算時間、下班、永遠在最上層、設定、紀錄、隱藏、結束。
- **找不到金幣圖示？** Windows 11 可能會把它收在工作列右下角的「^」（隱藏的圖示）裡。可以把它拖到工作列上，以後就一直看得到。
- **移動視窗**：按住視窗拖曳就能移動。每個版型的位置都會記住。
- **版型**：
  - U1 經典直式
  - U3 遊戲畫面
  - U5-B 橫向極簡
  - U7 桌面寵物：只有寵物和金額，背景透明
  - M3 迷你徽章：「縮成迷你」，在迷你徽章上點兩下就回到原本的版型
- **不會搶走打字焦點**：點桌面寵物（U7）或迷你徽章（M3）時，你正在打字的程式會保有鍵盤焦點，可以放心戳寵物。
- **永遠在最上層**：每個版型可以分開設定，預設只有 U7 和 M3 會置頂。
- **Alt+F4 只會隱藏視窗**，程式還在背景算錢。要真正關閉，請用選單裡的「結束」。

## 隱藏視窗與防截圖

- **快速隱藏快捷鍵**：預設是 Ctrl+Alt+H，按一下全部隱藏，再按一下恢復。
  - 要換的話：「設定」→「隱私」，點快捷鍵的框，再按下新的組合鍵（要有 Ctrl 或 Alt）。
  - 如果這組按鍵已經被其他程式使用，錢進中會提示你，請換一組。
- **視窗藏起來了，怎麼叫回來？** 任選一種：
  - 按快速隱藏快捷鍵。
  - 在工作列的金幣圖示上點兩下。
  - 在金幣圖示上按右鍵，選「顯示」。
  - 再點兩下 `錢進中.exe`，原本開著的錢進中就會出現。
- **防截圖（預設開啟）**：自己的螢幕照樣看得到錢進中，但是分享螢幕（例如 Teams 會議）、錄影、截圖都拍不到它。
  - 比較舊的 Windows 10（2004 以前的版本）沒辦法完全隱形，會拍到一塊黑框。
  - 要關掉的話：「設定」→「隱私」→「分享螢幕、錄影、截圖時隱形」。

## 開機自動啟動

- 預設開啟。錢進中只會寫入「目前使用者」的開機項目，不需要系統管理員權限。
- 要關掉：「設定」→「開機」→ 關閉「登入 Windows 後自動開啟」。

## 資料存放在哪裡

按 `Win + R`，貼上下面的路徑，按 Enter，就能打開資料夾。

- `%AppData%\錢進中`：你的資料。
  - `settings.json`：設定（包含薪資）。
  - `history.json`：每天的紀錄。
  - `window.json`：視窗位置。
  - 換電腦時，把這個資料夾複製過去就能接著用。
- `%LocalAppData%\錢進中`：程式自己用的檔案，刪掉也沒關係，下次開啟會重新產生。
  - `app\`：程式執行時需要的檔案。
  - `WebView2\`：顯示畫面用的瀏覽元件資料。
  - `error.log`：發生錯誤時的紀錄。

這些資料只存在這台電腦裡，錢進中不會把它們上傳到任何地方。

## 移除

錢進中沒有安裝任何東西到系統裡，照下面做就移除乾淨了：

1. 在設定裡關閉開機啟動：「設定」→「開機」→ 關閉「登入 Windows 後自動開啟」。
2. 關閉程式：右鍵選單 →「結束」。
3. 刪除 `錢進中.exe`。
4. 刪除 `%AppData%\錢進中` 與 `%LocalAppData%\錢進中` 這兩個資料夾（按 `Win + R`，貼上路徑打開，再刪除）。

如果先刪了 exe、忘了第 1 步：開機項目會留下一筆找不到檔案的紀錄，不會造成問題。想清掉的話，到「工作管理員」→「啟動應用程式」，把「錢進中」停用。

## 常見問題

- **出現「這台電腦缺少 Microsoft Edge WebView2 執行階段」**：請照「系統需求」安裝 WebView2，再重新開啟。
- **出現「錢進中發生錯誤」或「無法顯示畫面」**：詳細資訊記錄在 `%LocalAppData%\錢進中\error.log`。重新開啟通常就會好；如果一直發生，請把這個檔案交給提供程式給你的人。
- **金額不對**：先確認「設定」→「薪資」的金額和計算方式，再看起算時間對不對（右鍵選單 →「調整起算時間」）。
- **會不會拖慢電腦？** 錢進中很輕量。視窗隱藏或螢幕鎖定時，動畫會暫停。
