# 錢進中 — 設計文件

日期：2026-11-11
狀態：草稿（等使用者確認）

---

## 1. 這是什麼、為什麼要做

**錢進中**是一個 Windows 桌面小程式，主題是「工作的動力」。上班的時候，畫面上一直看得到**今天已經賺到的錢**往上跳，旁邊有一隻可愛的小寵物（貓咪或黃金鼠）陪著一起努力打字、午休、下班。看到錢一直增加，就有動力一直工作。

成功的樣子：
- 開機登入後不用做任何事，它就自己開始算錢，金額一直在跳。
- 隨時瞄一眼就知道：現在幾點、是上班中／午休中／可以下班、已經上班多久、今天賺了多少。
- 寵物夠可愛、動作夠多，讓人想點牠、餵牠、看牠。
- 不干擾工作：不吵、不跳系統通知、不吃 CPU。

## 2. 目標、非目標、反目標

**目標**
- 即時顯示今日收入（每秒更新、數字滾動跳動），以及日期、時間、狀態、已上班時間。
- 自動判斷上班起算時間，也能手動開始、手動調整起算時間。
- 多款寵物、多種版型可以切換，寵物有多種狀態動作和互動。
- Win10／Win11 直接執行，一個 `.exe`，不需要使用者另外安裝任何東西。

**非目標（這版不做）**
- 加班費、勞健保、稅金等薪資計算。
- 國定假日行事曆（改用「今天休假」手動開關）。
- 雲端同步、多台電腦、多使用者。
- 安裝程式（只發一個免安裝 `.exe`）。
- macOS／Linux。

**反目標（就算功能都對，發生這些也算失敗）**
- 預設會發出聲音，或跳出 Windows 系統通知打斷工作。
- 平常待機時吃掉明顯的 CPU／電力（目標：只顯示桌面寵物時，平均 CPU 低於 3%）。
- 需要系統管理員權限才能跑或才能開機自動啟動。
- 電腦缺少 WebView2 時直接閃退，沒有任何說明。
- 寵物或透明視窗擋住使用者點擊桌面上的其他東西（透明的部分必須讓滑鼠點穿過去）。

## 3. 限制

- 平台：Windows 10（1903 以上）與 Windows 11，64 位元為主（32 位元能跑更好，但不強求）。
- 執行環境只能依賴系統內建的東西：.NET Framework 4.8（Win10 1903+ 與 Win11 內建）＋ Microsoft Edge WebView2 Runtime（Win11 內建；Win10 透過 Windows Update／Edge 幾乎都已具備）。
- 開發機（使用者這台）**沒有安裝** .NET SDK、Node.js、Visual Studio；有內建的 `csc.exe`（C# 5，.NET Framework 4.8.1）、Python、git。建置流程不能要求使用者安裝開發工具；需要的套件（例如 WebView2 SDK 的 NuGet 套件、字型）可以下載放在專案的 `tools/`、`vendor/` 資料夾內，下載前要先取得使用者同意。
- 不需要管理員權限：開機自動啟動用目前使用者的登錄機碼（HKCU Run）。
- 介面語言：繁體中文。貨幣：新台幣（NT$），金額顯示到小數點後 2 位。

### 4.4 錢與時間怎麼算
- 薪資設定：**月薪**或**時薪**擇一。月薪模式可選日薪＝月薪 ÷ **30** 或 ÷ **22**（工作日），預設 ÷22。時薪＝日薪 ÷ 每日工時。
- 每日工時 **8 小時**；**12:00–13:00 午休不算錢**（金額暫停、狀態顯示「午休中」）。
- 起算時間：彈性上班（約 8–10 點），**預設每天第一次登入或解鎖 Windows 時自動起算**；也可以手動按「開始上班」；開始後可以手動調整起算時間（例如改成 8:45），金額立即重算。
- 工作時數（扣掉午休）滿 8 小時 → 狀態「可以下班」，**金額停住不再增加**。例：8:30 起算 → 17:30 可以下班。
- 下班電腦處理方式：使用者通常**只鎖定螢幕／睡眠**，不關機。
- **金額只依時鐘計算**：鎖定螢幕、睡眠都不影響（開會離開座位照樣算錢）。
- **提早下班**：介面上有「下班」按鈕（右鍵選單、系統匣也有），按下後今天的金額停在那一刻，狀態變成「已下班」。
- **忘記按下班**：如果某天最後一次鎖定／睡眠的時間早於應下班時間，而且之後當天沒有再回來，隔天第一次開啟時寵物會問：「昨天是不是 16:02 就下班了？」可以選「對，用那個時間」或「沒有，照原本的算」，結果寫進歷史紀錄。
- **週六、週日不自動起算**，但可以手動開始。

### 4.5 動力加成（全部要做）
- **里程碑慶祝**：每賺滿一個整數（預設 NT$100）跳出金幣／彩帶特效＋寵物開心。
- **今日進度條**：完成百分比＋距離下班倒數。
- **金額換算成物品**：例如「可以買 18.9 杯珍奶」，物品清單可自訂（預設：珍奶 65、便當 100、拿鐵 120，輪流顯示）。
- **本月累計**：記錄每天賺多少，顯示本月累計與簡單的歷史紀錄。

### 4.6 寵物互動（全部要做）
- **點牠／摸頭**：開心的表情和愛心；短時間連點很多下會生氣。
- **餵零食**：每達成一次里程碑得到一個零食（貓：小魚乾；鼠：瓜子），零食數量顯示在介面上，點「餵食」寵物會吃得很開心。
- **對話泡泡**：不定時冒出加油打氣或吐槽的話（依時間、狀態、金額變化內容）。
- **心情／體力值**：上班時體力慢慢下降、午休恢復；摸摸和餵食讓心情上升。

### 4.7 其他已確認
- 音效：要有，**預設關閉**，在設定裡打開。
- 下班提醒：**只有寵物慶祝**，不跳 Windows 通知。
- 下班後程式還開著：寵物**先慶祝，然後背起包包在桌上等你**，偶爾催你「可以走了！」。

### 4.8 使用對象與隱私
- **也會給同事、朋友用**，會在別人的公司電腦上執行。因此：
  - 預設值要通用（不能寫死使用者自己的薪水），第一次開啟時引導設定薪資。
  - 不能有容易被防毒軟體誤判的做法（不用加殼、不混淆、不注入其他程式），只寫入自己的資料夾與 HKCU 開機啟動機碼。
  - exe 沒有數位簽章，第一次執行可能出現 Windows SmartScreen 提示；要附一份簡短的使用說明（如何「仍要執行」、資料存在哪裡、如何移除）。
  - 缺少 WebView2 的 Win10 電腦要能顯示清楚的說明。
- **螢幕分享時保護薪水**：
  - 所有視窗預設設定為**螢幕分享、錄影、截圖都拍不到**（自己的螢幕上照樣看得到）；設定裡可以關掉這個保護。
  - 另有一組**快速隱藏快捷鍵**（全域，預設 Ctrl+Alt+H，可在設定修改），按一下全部隱藏、再按一下恢復。

## 5. 我的規劃（使用者還沒逐項確認，建置者可以照做，有更好做法可調整）

以下每一項都是**我的決定**，寫在這裡讓使用者審閱。

### 5.1 寵物狀態與動作
每個造型都要有以下狀態；不必每個狀態都重畫整隻，建議做成「身體姿勢＋表情層＋道具層」的組合（眼睛：張開／眨眼／開心 ^^／想睡／生氣；嘴巴；道具：咖啡杯、便當、Zzz、包包、零食）。趴睡、被拎起來這類姿勢和打字差很多的，需要另外畫。

**審稿關卡（使用者已確認要）**：所有新動作在放進程式之前，先做一頁「8 個造型 × 所有狀態」的 HTML 預覽給使用者看，確認可愛、OK 之後才整合。使用者對外觀要求高，前面已經改了好幾輪，預期可能會再改一兩次。

| 狀態 | 動作 |
|---|---|
| 未上班（開機前、週末、休假） | 發呆、打瞌睡 |
| 上班中 | 打字（主要動作），隨機穿插：伸懶腰、打哈欠、喝咖啡、盯著螢幕、抓頭；體力低時打哈欠變多 |
| 專心衝刺（下班前 30 分鐘） | 打字變快、冒汗或燃燒特效 |
| 午休中 | 趴在桌上睡覺（Zzz），偶爾吃便當 |
| 可以下班 | 慶祝（跳躍、彩帶）→ 背包包在桌上等，偶爾催你下班 |
| 被摸 | 開心表情＋愛心 |
| 連點太多下 | 生氣（鼓臉、冒煙），幾秒後恢復 |
| 被餵食 | 接住零食、吃東西 |
| 里程碑 | 開心跳一下＋金幣特效 |
| 被拖曳（U7） | 被拎起來晃來晃去的樣子 |

### 5.2 版型切換方式
- 右鍵點寵物或視窗任何地方 → 自訂右鍵選單：切換版型（U1／U3／U5-B／U7）、縮成迷你（M3）、餵食、開始上班／調整起算時間、下班、設定、隱藏、結束。
- 系統匣（右下角）常駐圖示，選單內容同上；點兩下顯示／隱藏。
- M3 迷你徽章：點兩下回到原本的版型。
- U7 和 M3 預設「永遠在最上層」；U1／U3／U5-B 預設不置頂，可在右鍵選單切換。
- 每個版型記住自己的視窗位置（和螢幕 DPI 無關，搬到不同螢幕也正常）。
- 拖曳：U7、M3 直接拖寵物或徽章移動；U1／U3／U5-B 拖標題列或空白處移動。

### 5.3 設定畫面
在主視窗內以 A1 風格的面板呈現：
- 薪資：月薪／時薪、金額、日薪除數（30／22）。
- 工時：每日工時（預設 8）、午休時段（預設 12:00–13:00）。
- 起算：自動（第一次登入／解鎖）或手動；工作日（預設週一到週五）；今天休假開關；調整今天的起算時間。
- 寵物：選動物與造型（顯示 8 個可選造型的預覽）、寵物名字。
- 版型：預設開啟版型、是否置頂。
- 動力加成：里程碑金額（預設 100）、換算物品清單（名稱、價格、圖示）。
- 音效：開關（預設關）、音量。
- 開機自動啟動：開關（預設開）。
- 隱私：螢幕分享時隱形（預設開）、快速隱藏快捷鍵（預設 Ctrl+Alt+H）。
- 第一次開啟：引導設定薪資、選寵物，其餘用預設值。

### 5.4 歷史紀錄
- 每天記錄：日期、起算時間、結束時間（滿 8 小時的時間點，或按「下班」的時間，或隔天確認的提早下班時間）、當天收入。
- 「紀錄」面板：本月每日長條圖＋本月合計＋前幾個月的月合計。
- 本月累計＝本月已結束各天＋今天目前的收入。

### 5.5 起算時間判斷細節
- 程式隨使用者登入自動啟動，之後一直常駐。
- 「今天第一次活動」＝當天第一次的登入、解鎖、或從睡眠喚醒後解鎖；以 Windows 的工作階段事件（解鎖、登入）與電源事件（喚醒）偵測。
- 若程式是當天稍晚才被手動打開（錯過了第一次活動），嘗試從不需要管理員權限就能讀的 Windows 系統事件記錄找今天最早的登入／喚醒時間；找不到就以開啟當下為準，並提醒使用者可以手動調整。
- 一天的分界點在凌晨 04:00（避免半夜還開著時跨日出錯）。
- 週末與「今天休假」不自動起算。

### 5.6 數字跳動的呈現
- 金額每約 0.1 秒更新一次，每一位數用「滾輪」動畫翻動（最後一位直接跳，避免糊掉），並不時冒出「+0.08」的小字往上飄。設計稿的做法見 `docs/prototypes/shared.js` 的 `Odo` 類別。

### 5.7 音效
- 不放音檔，用瀏覽器的 Web Audio 即時合成簡單音效（金幣叮、寵物叫聲、下班小樂句），預設關閉。

## 6. 技術做法（我的決定）

- **外殼**：C# Windows Forms 程式（.NET Framework 4.8），內嵌 **WebView2** 顯示介面。
- **介面**：HTML／CSS／SVG／JavaScript（不使用任何前端框架或建置工具，直接寫原生 JS 模組），延續設計稿的寫法；寵物全部是 SVG 向量繪製加 CSS 動畫。
- **單一 `.exe`**：網頁檔、字型、WebView2 的 .NET 函式庫都打包成資源嵌入 exe；執行時解壓到 `%LocalAppData%\錢進中\` 使用。WebView2 的使用者資料也放這裡。
- **資料**：設定與歷史紀錄存成 JSON，放在 `%AppData%\錢進中\`。
- **編譯**：用 Windows 內建的 `csc.exe`（或下載放在專案內的較新版 C# 編譯器套件，由建置者決定）＋一個 PowerShell 建置腳本，產出 `錢進中.exe`。不需要 Visual Studio。
- **透明無邊框視窗（U7、M3）**：需要「每個像素透明」的視窗，讓寵物看起來直接站在桌面上，透明的地方滑鼠要能點穿。這是技術上**最有風險**的一塊，建議**開工第一步先做一個小實驗驗證**；如果真的做不到完全透明，退而求其次的方案（例如沿寵物輪廓裁切視窗、或保留一個小底板）要先回報使用者再決定。
- **缺少 WebView2 時**：顯示友善的對話框說明，附上微軟官方下載連結，不要閃退。
- **效能**：視窗隱藏、縮小或螢幕鎖定時暫停動畫；蠟筆等使用 SVG 濾鏡的造型要確認 CPU 用量在預算內。
- **高 DPI**：支援每個螢幕不同縮放比例（PerMonitorV2）。
- **螢幕分享保護**：用 Windows 的視窗顯示保護（排除於擷取之外，Win10 2004 以上支援；更舊的系統退而用「擷取時顯示黑色」）。快速隱藏用全域快捷鍵註冊。
- **相容性測試**：主要在這台 Win11 測試；目前沒有 Win10 測試機，Win10 相容性靠「只用內建元件＋缺 WebView2 時的說明畫面」來保障，交付時在說明文件註明。

## 7. 留給建置者決定的事

- 程式碼的資料夾結構、C# 與 JS 之間的溝通方式（WebView2 訊息）。
- 寵物動作系統的實作方式（只要達到 5.1 的狀態列表）。
- 對話泡泡的台詞內容（語氣可愛、上班族共鳴，每種狀態至少 5 句）。
- 歷史長條圖的畫法、設定面板的版面細節（維持 A1 風格）。
- 使用較新版 C# 編譯器與否、如何打包資源。
