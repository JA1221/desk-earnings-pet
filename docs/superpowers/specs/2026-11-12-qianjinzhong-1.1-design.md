## 1. 這是什麼、為什麼要做

錢進中 1.0 讓人看著今天賺的錢往上跳、有寵物陪著上班。1.1 加上兩件跟「健康」有關的事，另外新增三種版型：

- **休息提醒**：使用者的原話是「坐太久會忘記活動活動或是喝水」。所以每坐一段時間，寵物會捧著水杯來「敲窗」，叫你起來動一動、順便喝口水，並記下今天喝了幾杯。
- **番茄鐘**：使用者的原話是「想專心時用番茄鐘」。專心 25 分鐘、休息 5 分鐘。專心時寵物也戴上耳機一起專心，提醒先排隊不打擾。
- **新版型**：U10 頂端小膠囊、U12 健康儀表板、U13 番茄鐘優先。

成功的樣子：
- 坐太久時，寵物會讓你**真的注意到**，並起來動一下。但提醒不會煩到讓你想把它關掉。
- 有在用的人，一眼就看得到今天喝了幾杯水、完成幾顆番茄。沒在用的人，畫面跟 1.0 一樣。
- 月底打開紀錄，看得出這個月有沒有好好喝水。
- 給同事用時，第一次開啟就能決定要不要提醒，不用再去翻設定。

## 2. 目標、非目標、反目標

**目標**
- 一個休息提醒：每隔一段時間叫你起來動、順便喝水。「起來動」和「喝水」可以分別開關，共用一個間隔。
- 喝水記杯數，一天有目標杯數。
- 番茄鐘：專心、短休息、長休息，從任何版型都能開始和停止。
- 五個現有版型（U1、U3、U5-B、U7、M3）都能顯示杯數和番茄數；沒在用時不顯示。
- 新增三個版型：U10、U12、U13。
- 設定新增「健康」分頁。第一次開啟的引導多一步問要不要提醒。
- 紀錄頁新增「健康月曆」。
- 寵物新增幾個動作：敲窗揮手、捧水杯揮手和喝水、戴耳機專心。

**非目標（1.1 不做）**
- Windows 系統通知（toast）。使用者選了「寵物來敲窗」，沒有選「＋Windows 通知」。
- 提醒音效。使用者選了「寵物來敲窗」，沒有選「＋聲音」。
- 寵物示範伸展操。使用者選了「不用，提醒就好」。
- 「延後多久」的多種選項（30 分鐘、1 小時、今天不再提醒）、「這顆番茄在做什麼」、「輕鬆／標準／認真」一鍵預設、每週摘要和徽章。這些是設計稿過程中提過、但使用者沒有選的功能。
- 喝水另外設間隔、起來動和番茄另外設每日目標（4.9）。
- 設計稿 G 區沒被選到的版型：U8、U9、U11、U14、U15。
- 雲端同步、跨電腦合併紀錄（同 1.0）。

**反目標（就算功能都對，發生這些也算失敗）**
- 提醒搶走鍵盤焦點，讓使用者打字打到一半跑掉。
- 上班前、午休、下班後、休假日、週末還在提醒。
- 使用者按了 Ctrl+Alt+H 藏起來（多半是在開會或分享螢幕），提醒卻自己跳出來。
- 提醒一天跳太多次，或一次跳好幾個泡泡疊在一起。
- 專心中（番茄鐘）被寵物聊天或提醒打斷。
- 平常待機的 CPU 比 1.0 明顯變高。倒數圈、膠囊這些新東西不能做成一直在跑的動畫。
- 升級到 1.1 後，1.0 的設定或歷史紀錄不見或被改掉。

- 1.0 設計第 3 節的限制全部沿用：平台、只依賴內建元件、不需要管理員權限、繁體中文、只寫自己的資料夾和 HKCU Run。
- 1.0 已經做好的行為不能被改壞，包括算錢、起算時間、螢幕分享隱形、快速隱藏、點穿透明區、相容模式（不透明背景）和各版型的焦點規則。

### 4.2 提醒

- **提醒強度：寵物來敲窗。**
  - 寵物停下工作，捧著水杯揮手，冒出一個比平常大的泡泡，上面有「喝了」「起來了」「等一下」三個按鈕（4.9）。
  - 按了才會收起來；按「等一下」或都不理它，過一陣子會再叫一次。
  - 不跳 Windows 通知，不發出聲音。
- **提醒樣式：B 方案 1「大泡泡」。** U1 的泡泡可以蓋到上面的狀態那行。
- **喝水時刻：B 方案 1「寵物捧著水杯」。** 用在有問喝水的提醒泡泡上。
  - 按「喝了」：寵物也喝一口，杯數跳一下 +1，然後回去工作。
  - 今天喝滿目標：寵物冒愛心、說一句誇你的話。
- **喝水要記杯數**：點一下記一杯，畫面顯示「今天 3／8 杯」，紀錄頁也看得到。
- **起來動一動時，寵物不示範伸展動作。**

### 4.3 番茄鐘

- **專心時寵物進入專注模式**：戴上耳機拚命打字，不講話、不打擾。
- **番茄鐘樣式：C 方案 2「寵物外面一圈」。**
  - 一個大圓圈圍著寵物慢慢倒數，像時鐘一樣，下面寫還剩幾分鐘。
  - 休息時圓圈變綠色。
- **專心到一半鎖螢幕離開（例如被叫去開會）：照算**，時間到就算完成。
- 番茄鐘的休息時間到了，寵物伸懶腰叫你起來，這次也算一次「起來動」。

### 4.9 介面簡化（使用者 2026-11-12 選定，1.1 的部分）

使用者的原話：「簡化：1 採用(但心情體力餵食等等 不要進入房間的介面)、2 採用、3 不要、4 採用、5 不要、6 採用、7 採用、8 採用、9 採用、10 不要、11 不要、12 採用、13 採用」。下面是會改到 1.1 的幾項（編號同簡化稽核）。

- **6. 一個提醒，不是兩個。**
  - 每 N 分鐘（預設 50）一次：「起來動一動，順便喝口水～」，寵物捧著水杯揮手。
  - 按鈕：「喝了」＝起來動＋記一杯；「起來了」＝只算起來動；「等一下」＝10 分鐘後再叫。
  - 「起來動」和「喝水」兩個開關都還在。兩個都開就問兩件事；只開一個就只問那件事，用那件事自己的說法和按鈕。
  - 喝水沒有另外的間隔。
- **7. 健康設定看得到的只有 5 個。**
  - 看得到的：起來動 開關、喝水 開關、每幾分鐘（一個間隔，50）、一天幾杯（8）、專心幾分鐘（25）。
  - 自動算的：起來動目標＝每日工時 ÷ 間隔（8 小時 ÷ 50 分 ≈ 9 次）；番茄每日目標＝一輪（每幾顆長休息，4 顆）。
  - 收在「進階」裡的：短休息、長休息、每幾顆長休息、今天已喝 − ＋。
  - 配合第 6 項，兩張提醒卡合成一張「休息提醒」，再加「番茄鐘」卡。仍是 D 方案 1 的卡片樣式。
- **8. 沒在用的數字不顯示。**
  - 杯數：喝水開著，或今天記過水，才顯示。
  - 番茄數：今天完成過番茄，或正在專心，才顯示。
  - U1、U3、U5-B 的「開始番茄鐘」按鈕一直都在。
  - U12（健康儀表板）的三個圈一直都在。
  - 沒在用的人看到的就是 1.0 的樣子。
- **2. 右鍵選單照使用頻率排（1.1 的部分）。**
  - 最上面一組是最常按的：「記一杯水」（旁邊寫 3/8）、「開始番茄鐘」，再來是 1.0 的「餵食」。
  - 「膠囊位置」收在「版型 ▶」裡，只有用 U10 時才出現。
- **9. 設定分頁。** 1.0 簡化成 4 個分頁後，1.1 加「健康」，共 5 個。
- **12. 版型。**
  - 膠囊位置只能用拖的或用右鍵選單改，設定裡沒有。
  - 設定的版型區只留「相容模式」和 1.1 的「省電模式」兩個開關。

## 5. 我的規劃（使用者還沒逐項確認，建置者照做，有更好做法可調整）

以下每一項都是**我的決定**，並已依 4.9 的簡化改好。

### 5.1 什麼時候會提醒

**只在「上班中」提醒。** 上班中也包含下班前 30 分鐘的衝刺。以下情況完全不提醒，計時也不跑：
- 還沒開始上班；
- 午休；
- 可以下班或已下班；
- 今天休假；
- 週末沒有開始上班。

**提醒計時**（只有一個，起來動和喝水共用）
- 開始上班時從 0 開始算。
- 鎖住螢幕的時間不算進去。
  - 一次鎖超過 **5 分鐘**，當作你已經離開座位活動過了：計時歸零，並算一次「起來動」。
  - 鎖不到 5 分鐘：回來後從原本的時間繼續算。
- 以下情況也會讓計時歸零：午休結束、按了提醒的「喝了」或「起來了」、開始番茄鐘的休息。
- 只開喝水時，不管從哪裡記一杯水，計時也歸零。
- 算到設定的分鐘數就提醒。

**泡泡問什麼**
- 看兩個開關和今天的杯數：
  - 起來動、喝水都開：「起來動一動，順便喝口水～」，按鈕「喝了」「起來了」「等一下」。
  - 只開起來動，或今天已經喝滿目標：「坐好久了，起來動一動！」，按鈕「起來了」「等一下」。
  - 只開喝水：「喝口水吧～」，按鈕「喝了」「等一下」。
  - 只開喝水、而且今天已經喝滿目標：當天不再提醒。記杯數還是可以繼續記。
- 畫面上任何時候最多只有一個提醒泡泡。提醒開著時，寵物不冒一般的聊天泡泡。

**按鈕的規則**

| 按鈕 | 結果 |
|---|---|
| 「喝了」 | 杯數 +1，算一次起來動，計時歸零（起身去倒水也是起來動） |
| 「起來了」 | 寵物開心一下，算一次起來動，計時歸零 |
| 「等一下」 | 泡泡收起來，**10 分鐘**後同一個提醒再來一次 |
| 都不按 | 泡泡一直留著。寵物每隔 **2 分鐘**再揮一次手，但不會再多冒泡泡 |

如果提醒還開著時進入午休、下班或休假，泡泡就安靜地收起來。

**提醒先等著、不跳出來的情況**

以下情況，到時間的提醒先排隊，等情況結束後過 **3 秒**再出來。這條規則也適用番茄鐘的泡泡（專心結束、休息結束），但番茄鐘倒數本身照跑：
- 錢進中被藏起來（快速隱藏鍵，或系統匣的隱藏）；
- 正在專心（番茄鐘）；
- **Windows 回報目前是全螢幕或簡報模式**（例如投影片放映、全螢幕遊戲或影片）。這是因為投影機和會議室螢幕不在螢幕分享隱形的保護範圍內。

**番茄鐘泡泡和提醒怎麼搭配**（畫面上一樣最多一個泡泡）
- 開始番茄鐘時，如果有提醒泡泡還開著：泡泡收起來，提醒回到排隊。
- 專心結束時，排隊中的提醒這樣處理：
  - 開始休息本來就算一次起來動，所以提醒本身取消、計時歸零。
  - 如果它有問喝水（喝水開著、今天還沒喝滿），休息泡泡多一行「順便喝口水吧～」和一顆「喝了」，見 5.2。
- 按了「跳過休息」：計時不歸零，所以之後到時間一樣會排隊，等下一次休息再說。
- 番茄鐘的泡泡和提醒一樣，都不按時寵物每 2 分鐘再揮一次手。
- 番茄鐘是使用者自己開始的，所以它的泡泡在午休、下班後也會出現。休息提醒在那些時段還是不出現。

**提醒時把視窗拉到最前面**
- U1、U3、U5-B、U12、U13 平常可能被 Excel 之類的視窗蓋住，蓋住就看不到提醒，「敲窗」就沒意義了。
- 所以提醒出現時，視窗移到所有視窗的最上面，但**不搶鍵盤焦點**，正在打的字不受影響。
- 泡泡收起來後，恢復原本的置頂設定。
- U7、M3、U10 本來就在最上層，不受影響。

**不同版型的提醒長什麼樣**

| 版型 | 樣子 |
|---|---|
| U1、U3、U7、U13 | 大泡泡，冒在寵物旁邊 |
| U5-B | 太扁放不下泡泡（設計稿 C 區有畫 U5-B 的休息狀態）：上面那行字換成會晃動的「起來動一動～」，小按鈕接在同一行後面，視窗不變大 |
| M3 | 整個圓圈像在敲門一樣晃一下，旁邊冒一個小泡泡和按鈕（設計稿 B 區的 M3） |
| U10 | 膠囊像來電一樣變寬，按鈕在膠囊上 |
| U12 | 「起來動」那圈發光，寵物在下面用泡泡說，按鈕在泡泡上 |

### 5.2 番茄鐘細節

- **開始和停止的地方**
  - 右鍵選單和系統匣選單最上面一組：「開始番茄鐘」。進行中變成「停止番茄鐘（還剩 12 分）」。
  - 版型上的按鈕：
    - U1：小膠囊的「開始」；
    - U3：番茄按鈕；
    - U5-B：右欄番茄按鈕；
    - U10：展開後的按鈕；
    - U13：大圈圈。
  - 專心中再按同一顆按鈕就是停止。
- **什麼時候可以開始**：任何時候都能開始，包括午休和下班後，因為番茄鐘是使用者自己按的。完成的番茄算在開始那天。
- **專心中**
  - 寵物戴耳機打字。
  - 一般聊天泡泡關掉。被點的時候只回一次「專心中～」。
  - 休息提醒先排隊。
- **專心結束**
  - 番茄數 +1，休息**立刻開始計時**，不等按鈕。
  - 寵物伸懶腰，冒出泡泡「休息 5 分鐘！起來走走～」，小字寫「第 3 顆番茄完成」，按鈕是「好」和「跳過休息」。
  - 排隊中的提醒如果有問喝水，就併進這個泡泡：多一行「順便喝口水吧～」，也多一顆「喝了」按鈕（這裡的「喝了」只記一杯，起來動已經在開始休息時算過）。
  - 開始休息就算一次「起來動」，提醒計時歸零。
  - 按「跳過休息」：馬上開始下一顆。
- **長休息**：今天完成的番茄數是 4 的倍數時（預設），這次休息改成長休息。
- **休息結束**
  - 泡泡問「休息結束～要開始下一顆嗎？」，按鈕是「開始」和「先不要」。
  - 「先不要」：番茄鐘停止。
  - 都不按：泡泡留著，**不會自己開始**下一顆。
- **專心到一半停止**：這顆不算完成，不追問。
- **專心中剛好滿 8 小時可以下班**：錢照常停住，但下班慶祝和背包包等到這顆專心結束才開始。
- **鎖螢幕、藏起來、程式重新開啟**
  - 番茄鐘照樣倒數。
  - 程式關掉再打開，接著原本的時間繼續。
  - 關掉期間如果已經到時間，這顆照樣算完成（「照算」的原則）。
- **倒數圈（寵物外面一圈）**
  - 一般版型：圈住寵物，下面寫「還剩 N 分」。專心是番茄紅，休息是綠色。
  - M3：外圈暫時改成倒數，平常是今天的進度。
  - U10：膠囊上顯示倒數。
  - U12：「番茄」那圈改成倒數。
  - U13：本來就是大倒數圈。
  - 倒數圈**每秒更新一次就好**，不需要連續動畫。

### 5.3 記一杯水、杯數和番茄數的顯示

- **記一杯水的方法**
  - 提醒泡泡的「喝了」；
  - 右鍵選單和系統匣最上面的「記一杯水」（旁邊寫 3/8）；
  - 版型上的杯數按鈕：U1 小膠囊、U3 水杯按鈕、U5-B 右欄、U10 展開後、U12 喝水圈（前四個沒在用時不顯示，見 4.9 第 8 項）。
- **只顯示、不能按的地方**：U7 金額牌的小字、M3 的小貼紙。這兩個太小容易誤按，要記水請從右鍵選單。
- **記錯了怎麼改**：設定 → 健康 → 進階，有「今天已喝 N 杯 − ＋」可以改。
- **起來動的次數**：U12 的「起來動」圈和每日紀錄要用。以下各算一次：
  - 按提醒的「起來了」；
  - 按提醒的「喝了」；
  - 番茄鐘開始休息；
  - 上班中鎖螢幕超過 5 分鐘。
- 起來動的次數不管提醒有沒有開都照算。番茄鐘的休息也是，就算在午休或下班後休息，也算一次。

### 5.4 健康設定的內容（4.9 第 7 項）

| 卡片 | 項目 | 預設 | 範圍 |
|---|---|---|---|
| 休息提醒 | 起來動 開關 | 照引導的選擇 | |
| | 喝水 開關 | 照引導的選擇 | |
| | 每幾分鐘提醒 | 50 | 20–120，每格 5 |
| | 一天幾杯 | 8 | 1–20 |
| 番茄鐘 | 專心幾分鐘 | 25 | 10–90，每格 5 |
| 進階（點開才看到） | 短休息 | 5 分 | 1–30 |
| | 長休息 | 15 分 | 5–60，每格 5 |
| | 每幾顆長休息 | 4 | 2–8 |
| | 今天已喝 | − ＋ | |

- 自動算的：
  - 起來動目標＝每日工時（分鐘）÷ 間隔，無條件捨去，至少 1（8 小時、50 分 → 9 次）；
  - 番茄每日目標＝每幾顆長休息（4 顆）。
- 提醒關掉時，杯數、番茄數照樣能記；畫面上照 4.9 第 8 項，有在用才顯示。
- U12 三個圈的「滿」是：一天幾杯、番茄每日目標、起來動目標。

### 5.5 從 1.0 升級的人

- 1.0 的使用者（使用者本人和已經拿到 1.0 的同事）不會再走一次引導。
- 所以升級後**第一次開啟**時，單獨跳出引導那一步「要不要提醒你起來動、喝水？」，一樣預設打勾。
- 回答之後才記錄「問過了」。直接關掉不回答，下次開啟會再問。
- 還沒回答之前，**兩個提醒都先不開**，避免同事一升級就突然被提醒。
- 1.0 的設定、歷史紀錄、版型位置全部保留，不改動。

### 5.6 紀錄要存什麼

- 每天記錄：喝了幾杯、完成幾顆番茄、起來動幾次，以及**當天的喝水目標**。存目標是為了之後改了目標，舊月曆的顏色不會跟著變。
- 寫檔的方式和 1.0 的歷史紀錄一樣安全：先寫到磁碟、保留 .bak。
- 當天的杯數和番茄數，在程式重開、電腦當機後都要還在。
- **健康月曆**
  - 跟著收入圖的月份切換。
  - 格子顏色依「當天杯數 ÷ 當天目標」分深淺；達標是最深的藍色加一個勾。
  - 右下角寫番茄數。
  - 沒有資料的日子留白；今天即時更新。

### 5.7 U10 頂端小膠囊的位置

- 四個位置：上方正中間（預設）、左下、中下、右下。
  - 「下」是指工作列正上方，用螢幕的工作區域計算。
  - 工作列在側邊或自動隱藏時也要正確。
- 選位置的地方：右鍵選單「版型 ▶ 膠囊位置」（只有用 U10 時出現）。設定裡沒有（4.9 第 12 項）。
- 也可以直接拖著走。放開時吸到**那個螢幕**上最近的四個位置之一，所以也能換到別的螢幕。
- 滑鼠移上去或提醒時會展開：在上方就往下展開，在下方就往上展開。
- 永遠在最上層、不搶焦點、膠囊以外的地方滑鼠點得穿，和 U7、M3 一樣。
- U12、U13 的視窗行為和 U1 一樣：一般主視窗、預設不置頂、可以拖曳。
- U5-B 變寬約 65px：保持原本的左邊位置，往右長。如果超出螢幕工作區域，就往內推回來。

### 5.8 寵物新動作與審稿關卡

新動作：

| 動作 | 用在哪裡 |
|---|---|
| 跳起來揮手（敲窗） | 只開「起來動」的提醒 |
| 捧著水杯揮手 | 有問喝水的提醒 |
| 喝一口 | 按「喝了」之後 |
| 戴耳機專心打字 | 番茄鐘專心中 |

- 休息時的伸懶腰，和喝滿目標時的開心加愛心，沿用 1.0 的動作。
- 和 1.0 一樣有**審稿關卡**：新動作先做一頁「10 個造型 × 新動作」的預覽給使用者看，使用者說 OK 才整合。
- 這一步要等貓 H2、貓 S4 的新造型選定之後再畫。
  - 新造型會先在 1.0 這邊挑好、併進去，所以預期 1.1 開工時已經定案。
- 寫程式時，提醒、番茄鐘和版型不用等美術：
  - 造型還沒有某個新動作時，先用最接近的 1.0 動作代替：揮手用慶祝，捧水杯和喝一口用喝咖啡，專心用打字。
  - 代替的動作只能在開發中用。正式發佈 1.1 時，10 個造型的新動作都要畫好並通過審稿。

### 5.9 省電模式和 CPU

1.0 留下一個沒達到的目標：U7 平常的 CPU 要在一個核心的 12% 以內。目前實測 P0 約 16%，蠟筆 S5 約 28%。

- 新增設定「省電模式」（預設關），放在設定 → 畫面。打開時：
  - 金額每秒更新 4 次，不是 10 次；
  - 拿掉一直在跑的裝飾動畫；
  - 寵物閒置時的小動作變少；
  - 蠟筆造型改用不會動的紋理。
- **目標**：打開省電模式時，U7 的 P0 和 S5 都在一個核心的 12% 以內。
- **量法**：跟 1.0 一樣，在這台電腦上量 錢進中.exe 加上它的 WebView2 子程序，60 秒的平均。
- 做完 5.9 列的項目和合理的繪圖優化後，如果還是達不到，**不擋發佈**。把實測數字回報給使用者，由使用者決定。
- 關掉時（預設）不能比 1.0 更耗。
- 1.1 新加的東西（小膠囊、倒數圈、三個圓圈）在沒有互動時不能有連續動畫。

### 5.10 1.0 留下的兩個小問題，順便修

- exe 旁邊有別的 WebView2 DLL、但讀不到時，現在會當作沒問題繼續跑。改成保守處理：一樣顯示訊息並結束。
- session.json 在「清掉」和「寫回磁碟」之間有一小段空窗，這段時間關機會漏記。要補上。

## 6. 技術做法（我的決定）

- **架構沿用 1.0**：C# 外殼、WebView2、原生 JS，不加框架和建置工具。
- **計時邏輯放在網頁端**，因為現有的上班狀態、午休和鎖螢幕判斷都在網頁端。
  - 計時要能用「假時鐘」測試，像 1.0 測算錢一樣。
  - 不要依賴 `setTimeout` 的長延遲，要照實際時間對帳，讓電腦睡眠回來也算得對。
- **外殼需要新增的能力**：
  - 告訴網頁「現在是不是全螢幕或簡報模式」。用 Windows 不需要權限的使用者通知狀態查詢，變化時通知網頁就好，不用一直問。
  - 「拉到最前面但不搶焦點」，以及之後恢復原本的置頂設定。
  - U10 需要的資訊：每個螢幕的工作區域，以及拖曳放開時吸附到最近的位置。
- **版本號**：1.1.0。設定 → 其他 → 關於顯示新版號。
- **使用說明更新**：`docs/使用說明.md` 和程式內建的 guide.txt 都要加上：
  - 提醒怎麼開關；
  - 番茄鐘怎麼用；
  - 三個新版型；
  - 「全螢幕和簡報時提醒會先等著」。

## 7. 留給建置者決定的事

- 檔案怎麼切，例如提醒、番茄鐘、健康紀錄各一個模組，或合併；外殼和網頁之間新增的訊息格式。
- 提醒和番茄鐘泡泡的台詞。語氣跟 1.0 一樣可愛、有上班族共鳴，每種提醒至少 5 句輪流說。
- 健康月曆的格子大小、深淺分幾階、週一或週日開頭。維持 A1 風格就好。
- U10 展開後的確切排版、U12 三個圓圈的畫法、U13 金額放左邊或下面：照設計稿，細節自己調到好看。
- 健康資料要放在現有的歷史紀錄裡，還是另外一個檔案。只要符合 5.6。
- 省電模式除了 5.9 列的，還要再省哪些。
